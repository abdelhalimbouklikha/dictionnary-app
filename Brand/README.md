# Identité LexiFR

`AppIcon-master.png` est le master sans masque arrondi. Les rendus iPhone sont
dans `LexiFR/Resources/Assets.xcassets/AppIcon.appiconset`.

Le master a été produit avec l’outil ImageGen intégré, catégorie `logo-brand`,
à partir de cette direction : icône iOS carrée premium et minimaliste pour un
dictionnaire français hors ligne, monogramme capital « L » aubergine avec signe
typographique/apostrophe corail, fond ivoire, silhouette lisible à 29 px, sans
livre, drapeau, Tour Eiffel, logo tiers, texte supplémentaire, ombre ni coins
arrondis intégrés.
