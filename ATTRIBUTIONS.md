# Attributions des données LexiFR

LexiFR utilise des données lexicales extraites du **Wiktionnaire en français**
par **Kaikki.org / Wiktextract**.

- Source éditoriale : [Wiktionnaire](https://fr.wiktionary.org/)
- Réutilisation et attribution : [Wiktionnaire — Réutilisation du contenu](https://fr.wiktionary.org/wiki/Wiktionnaire:R%C3%A9utilisation_du_contenu_du_Wiktionnaire)
- Extraction structurée : [Kaikki.org](https://kaikki.org/)
- Outil d’extraction : [Wiktextract](https://github.com/tatuylonen/wiktextract)

Le texte du Wiktionnaire est réutilisable sous **Creative Commons Attribution –
Partage dans les mêmes conditions 4.0 International (CC BY-SA 4.0)** ou,
suivant la compatibilité du contenu concerné, sous **GNU Free Documentation
License (GFDL)**. LexiFR attribue le projet Wiktionnaire et Kaikki, indique les
licences, et conserve le même régime de partage pour la base lexicale dérivée.

Les photos personnelles choisies avec PhotosPicker n’appartiennent pas à la
base lexicale, restent sur l’appareil et ne sont ni téléversées ni redistribuées.
LexiFR n’intègre aucune image provenant de Google Images : le bouton dédié ouvre
uniquement une page de recherche dans le navigateur.

La citation académique demandée par Kaikki pour Wiktextract est : Tatu Ylonen,
“Wiktextract: Wiktionary as Machine-Readable Structured Data”, LREC 2022.
